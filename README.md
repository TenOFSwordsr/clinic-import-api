# Clinic Directory Import API (WordPress plugin)

A custom WordPress plugin that exposes a key-authenticated REST namespace, `ahura/v1`, on
VisitAl (visital.ir), a Persian-language doctor/hospital directory running the Doctor Plus
theme. It exists so the doctoreto / nobat scraper work can push doctors, hospitals,
specialities, insurances, offices, opening times, patient reviews, WooCommerce products and
orders straight into the theme's own tables. Every write is an idempotent upsert keyed on
`external_id`. `AHURA-API.md` is the full endpoint reference.

**Suggested repo name:** `clinic-import-api`
**Stack:** PHP 7.4+, WordPress REST API, MySQL (`Dj3i_drplus_*` Doctor Plus tables), WooCommerce
**Status:** active
**Last modified:** 2026-09-10

## What it does

- `ahura.php` - plugin header, activation (generates the `ahura_api_key` option once, `dbDelta`s
  the `*_ahura_import_log` idempotency ledger), `X-Ahura-Key` auth middleware, and the part-1
  routes: `/doctors` + `/doctors/bulk`, `/comments` + `/comments/bulk`, `/hospitals`,
  `/specialities`, `/insurances`, `/terms`, `/times`, `/bookings`, `/products`, `/media`,
  `/users`, `/doctors/{id}/stats|views|thumbnail`, `/ping`, `/stats`, `/logs`, `/key/rotate`.
- `ahura-part2.php` - whole-site coverage: generic `/posts` CRUD for any post type/CPT, user
  admin, comment editing, WooCommerce orders, the sheyda wallet and withdrawals, chats, OTP,
  SMS log, wishlist, plus introspection endpoints `/elementor`, `/menus`, `/attachments`,
  `/options`, `/schema`, `/site` and a read-only `/sql` escape hatch.
- `ahura-part3.php` - regex classification of روانشناس (psychologist) and ماما (midwife)
  specialities, comment `rating` meta hooks, top-rated search ordering.
- `ahura-part4.php` - same for دندانپزشک (dentist) specialities, and injects the
  روانشناس‌ها / دندانپزشک‌ها tabs into the theme's search-results widget without editing theme files.
- `child-templates-search-results.php` - child-theme override of the Doctor Plus
  `templates/search/templates-search-results.php` that renders those extra sections.
- Doctor upserts also write the theme's runtime expectations: `specialist_code` user meta
  (شماره نظام پزشکی), `avatar` user meta, `_drplus_patient_review` comment meta, and
  `_drplus_total_scores` so the star average and review counter render correctly.

## Layout

```
ahura.php                  plugin header, activation, auth, part-1 endpoints (66 KB)
ahura-part2.php            generic posts/users/orders/wallet/runtime/schema endpoints
ahura-part3.php            psychologist + midwife detection, ratings, search ordering
ahura-part4.php            dentist detection, search sidebar tabs
child-templates-search-results.php   child-theme template override
AHURA-API.md               endpoint reference: bodies, status codes, curl/Python examples
```

## Running it

Copy the folder into `wp-content/plugins/` and activate; there is no build step, no Composer
and no autoloader. Part 2/3/4 are `include`d by `ahura.php`, so all files must stay together.

```bash
curl -s https://visital.ir/wp-json/ahura/v1/ping
```

Send Persian payloads as UTF-8 JSON from Python or a real HTTP client - `curl -d` under
Windows Git Bash mangles the bytes (documented in `AHURA-API.md`).

## Notes

- `child-templates-search-results.php` is not part of the plugin; it belongs in the Doctor Plus
  **child theme** at `templates/search/`, and depends on the plugin being active.
- The DB table prefix `Dj3i_` is hardcoded in the `AHURA_*` constants, so the plugin is pinned
  to this installation rather than portable.
- `POST /sql` is limited to SELECT/SHOW/DESCRIBE, but `GET /schema` and `/options` still expose
  the full table and option surface - do not run this on a publicly reachable staging site.
- `ahura_cors_headers()` sends `Access-Control-Allow-Origin: *` for all `ahura/v1` routes.
- `ahura-part2.php` says it was generated by `ahura_build_part2.py`; that generator is not in
  this folder, so parts 2–4 are maintained by hand.
- Keep the real API key out of the repo - `AHURA-API.md` calls this out explicitly.
